📸 Como Configurar o Instagram (Meta Graph API)

Passo a Passo
  1. Conta Profissional: Abra o Instagram no celular > Perfil > Configurações > Altere para Conta Profissional (Comercial/Creator) e vincule a uma Página do Facebook.
  2. Meta for Developers: Entre em developers.facebook.com > Meus Apps > Criar Aplicativo > Tipo Empresa (Business).
  3. Adicionar Produto: Adicione o produto API do Graph do Instagram ao aplicativo.
  4. Permissões no Explorer: Acesse o Graph API Explorer, selecione o seu App e adicione: instagram_basic, instagram_content_publish, pages_show_list, pages_read_engagement. Gere o token conectando sua conta.
  5. Instagram Account ID: No Explorer, consulte me/accounts?fields=name,instagram_business_account{id,username}. Copie o número do id.
  6. Token de 60 Dias: Abra o Access Token Debugger, cole o token gerado e clique em Estender Token de Acesso.
  7. Inserir no Painel: Cole o Account ID e o Token na aba Instagram & Meta e clique em Testar Conexão!

✨ Google AI (Gemini & Veo)

Google AI Studio
  1. Acesse o portal gratuito: aistudio.google.com.
  2. No menu esquerdo, clique em Get API key.
  3. Clique em Create API key e copie a chave gerada (começa com AIzaSy...).
  4. Cole na aba Google Gemini & Veo deste painel e salve!

✈️ Telegram Bot (Aprovação)

Controle Remoto
  1. No Telegram, converse com o @BotFather e digite /newbot. Defina o nome e username do bot.
  2. Copie o HTTP API Token fornecido.
  3. Converse com o @userinfobot no Telegram para descobrir o seu Id numérico pessoal.
  4. Cole ambos na aba Telegram Bot deste painel e salve!
